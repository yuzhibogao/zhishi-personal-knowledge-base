    提高语义理解能力

    当前离线规则支持常见主题的中英文别名与停用词过滤，不能替代通用语义模型。

    可在项目 work/.env 中配置现有的 Ollama 本地模型，或选择 DeepSeek / OpenAI 兼容服务，再重启后端。“模型辅助”会向所配置服务发送文档节选；服务可位于云端或本机。本地规则不调用语言模型。

    ONLINE_LLM_PROVIDER=deepseek
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-flash
LLM_API_KEY=在本机.env中填写你的密钥
EMBEDDING_MODE=mock

    真实向量检索使用 EMBEDDING_MODE=local 和 EMBEDDING_MODEL 配置。跨语言检索应选择支持中英文的模型；首次使用可能下载模型。切换模型后需重新分析文档建立对应索引。

    配置后重启后端，再在页面顶部切换在线模式。同一文库共用；切换不会批量重做旧资料。离线模式不调用语言模型 API；在线失败时资料仍会保留，可切回离线重新分析。
