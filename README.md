# 拾知 · 个人知识库

将文件和笔记保存在本机，按主题整理，再通过本地全文或模型辅助方式找回资料。

## 下载安装

**普通 Windows 用户**：在本仓库 Releases 下载 `Zhishi-Windows-x64-Portable.zip`，解压整个文件夹到可写目录，双击 `Zhishi.exe`。无需安装 Python、无需自己配置依赖。不要只复制 exe，也不要直接在压缩包里运行。Windows 10/11 x64 为目标平台，当前包未做代码签名；其他平台使用源码。

**开发者**：安装 Python 3.12 x64，进入 `work`，运行 `install_windows.bat`，完成后双击 `start.bat`。网页地址为 http://127.0.0.1:8000/ 。端口被其他项目占用时先关闭对应服务；启动器不会接管其他文库。

首次启动是空白文库，默认本地规则，不需要API密钥。GitHub源码和发布压缩包均不包含开发者的文档、数据库、API配置、日志或备份。

## 当前功能

- 收集资料：TXT、Markdown、PDF、DOCX、XLSX（单文件上限5MB）；可填写标题和分类，留空自动处理。
- 文库：分类树、资料筛选、批量移入分类、删除分类后归入未分类、一键分类。
- 阅读：保留新上传的原文件，PDF原件、Word/Excel网页预览；下载原件保留原格式。
- 笔记编辑：粘贴文字与悬浮窗笔记可编辑，退出时确认保存；Word/Excel目前为浏览和下载，不提供完整Office编辑器。
- 防重复：文件哈希和文本规范化/相似检查，发现重复提示，可由用户选择另存；不会自动清理历史重复。
- 检索：本地全文或模型辅助；检索百分比、阶段追踪、命中说明和原文证据。
- Windows悬浮收集：Ctrl+Alt+K打开，Ctrl+Enter保存，支持移动、缩放、置顶和连续录入。

## 本地规则与模型辅助

“整理模式”控制录入时的摘要、标签、分类；“检索方式”独立控制搜索。外接模型是可选项：在自己的 `.env` 配置服务商、URL、模型名和密钥，重启后再主动选择模型辅助。支持DeepSeek、OpenAI兼容服务、Ollama接口。

模型辅助会向配置的服务发送问题和文档节选，可能收费；“保存在本机”不代表开启远程模型时内容不外发。本地规则无需联网，不具有完整语义理解。普通便携包不包含本地大模型或FastEmbed。

## 限制与验证状态

扫描PDF没有完整OCR，多栏、公式和复杂表格提取可能不准确。模型检索最多60份候选，长文使用节选，因此仍可能漏检或误判。百分比是阶段估算，等待模型时不会虚报其内部完成度。

分类合并请求及两篇并行减少重复请求和排队，不保证固定提速倍数或准确率。当前发布不是全面质量评测结果；查看发布说明了解构建、语法与启动检查的实际完成情况。
