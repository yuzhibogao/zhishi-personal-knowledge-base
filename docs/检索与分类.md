# 检索与分类机制

本地全文查标题、摘要、分类、标签/别名和提取正文。查询分词并识别已知中英文主题，宽泛主题可单向扩展到具体实例。严格匹配需命中至少75%的概念组；扩大范围需命中任一组。排序结合覆盖率和字段权重。这不是概率准确率，不能完整理解复杂意图。

模型辅助独立开启：先生成最多5条检索表达，再在本地召回候选，用模型阅读最多60份候选的节选，按原问题判断。小文库也纳入没有词面命中的候选；大文库有召回上限。模型严格匹配保留direct，扩大范围加入related。宽泛主题的具体实例可直接相关；明确限制仍要满足。后端校验文档ID和原文引用，不允许虚构资料；服务失败明确回退本地。

检索进度按实际阶段估算：排队、准备、理解问题、候选召回、等待语义判断、引用校验、完成。显示候选、已检查、匹配、未纳入和异常数量；模型内部逐篇进度不可见，只在响应后更新已检查。完成100%，失败保留未完成百分比；后台最多2个并行检索、4个在途任务，内存结果约保留10分钟。

本地分类采用有限词典和上下文规则。外接模型依据主题、用途和现有目录分类，人工分类保留。无充分依据归未分类。小目录新资料可一次请求生成摘要/标签/分类，模板规则与采样长度保持；批量一键分类最多两篇并行，目录写入串行。尚未测量固定提速或准确率提升，效果需要实际样本评估。

资料和原件存储主要占磁盘；运行内存包括Python、Qt、分词器、解析器和临时检索对象。Windows“私有提交量”不等于文件总大小或全部实际RAM。发布包自带运行时，所以压缩包大小不能当作文库容量或常驻内存。
