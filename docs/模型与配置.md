# 模型与配置

源码版将 work/.env.example 复制成 work/.env；便携版首次启动自动复制程序旁的空模板。用文本编辑器填写自己的配置，重启后端。

```dotenv
ONLINE_LLM_PROVIDER=deepseek
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=填写供应商当前支持的模型ID
LLM_API_KEY=填写自己的密钥
EMBEDDING_MODE=mock
CLASSIFICATION_WORKERS=2
LLM_COMBINED_ORGANIZE=1
```

模板不预填密钥；模型名以供应商提供的实际可用ID为准。OpenAI兼容服务选择openai，Ollama选择ollama并填写本机地址与已安装模型名称。使用DeepSeek或其他远程服务不会下载其模型权重。
整理模式与检索方式是独立选项。界面“访问令牌”对应KB_API_TOKEN，仅用于本知识库接口认证，不是模型API Key。

设置 CLASSIFICATION_WORKERS=1 可降低批量并发；LLM_COMBINED_ORGANIZE=0 恢复分步整理。默认不加载FastEmbed，mock哈希向量不用于真实语义召回。源码高级用户可安装requirements-optional.txt并选择EMBEDDING_MODE=local，需要额外模型下载、资源和重建对应索引；便携包不含此可选依赖。

提示词位于app/prompts：organize为摘要标签，classify为分类，organize_classify合并两者，search_plan规划查询，search_rank判定相关性。保留模板占位符与JSON字段；修改影响下一次请求，不会自动重做旧资料。便携版提示词位于_internal/app/prompts。
