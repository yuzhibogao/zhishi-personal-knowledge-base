# 使用指南

## 初次启动
便携版解压后双击 Zhishi.exe；源码版先安装环境再双击 work/start.bat。启动器会启动后端、悬浮收集和浏览器。关闭网页不会结束后台服务；托盘右键“退出”只退出悬浮窗。后端进程可在任务管理器结束，关闭电脑也会结束；正在上传或编辑时先完成保存。

## 收集与管理
上传PDF、DOCX、XLSX、TXT或MD，或填写标题、分类与正文。标题和分类可选；批量文件上传时输入的标题和分类应用于本批文件。新文件原件保存在数据库中，文字用于检索。旧记录若原来没有保存原件，不能恢复原文件。
分类树点击后查看该分类与子类资料。可多选资料移入目标分类，也可在新分类中从文库选择资料。删除分类需要确认，资料归入未分类，不删除资料；“未分类·一键分类”只处理仍未分类的记录。
重复提示会自动关闭，也可手动关闭。选择另存会创建独立资料。

## 阅读和编辑
详情页可查看摘要、分类、标签和正文。笔记的编辑正文功能在退出时提示保存、放弃或继续编辑。PDF可原件阅读，Word/Excel提供网页预览和原件下载；不保证网页重现复杂版式、图表及公式表现。

## 悬浮窗
Ctrl+Alt+K呼出或隐藏，Ctrl+Enter保存，Esc隐藏。标题、分类、正文三个输入项；保存成功保留窗口与分类、清空当前标题和正文，以便连续录入。拖动标题栏移动，拖动边框缩放；最小320×240，初始400×300。

## 数据位置
源码版 work/data/kb.db；便携版程序旁 data/kb.db。自己的 .env 也在程序旁。移走便携文件夹时不要丢失data。备份时先关闭本项目后端，再复制整个data文件夹；分享给别人则使用干净发布包，不能直接分享已使用过的程序目录。
