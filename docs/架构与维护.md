# 架构与维护

源码结构：work/app为FastAPI后端与网页静态文件；work/floatbox为PySide6快速收集；work/launch.py为源码启动器；work/portable_entry.py为冻结程序入口；work/scripts为打包工具；docs为当前使用文档。

SQLite保存元数据、正文、分类、别名、原件和切片；默认data/kb.db。API只通过本机8000端口使用，默认本地规则。处理模式记录在app_settings，检索任务状态仅存内存。

Python 3.12 x64用于当前Windows构建。requirements.lock.txt是运行依赖闭包，requirements-build.txt加入PyInstaller；源码可用requirements-optional.txt启用可选本地向量模型。Docker只提供后端网页，不提供Windows悬浮窗。

构建：在work目录安装requirements-build.txt，执行python scripts/build_portable.py，输出dist/Zhishi；将模板、说明、第三方许可与整个程序目录一起发布。源码包使用python scripts/package_source.py，按白名单收录。不从个人数据库生成任何初始样本。

验证分层：语法和打包完成不代表功能或准确率达标。未做的Windows净机兼容、跨电脑、并发、大文库、扫描PDF、模型质量等评测应在发布说明里明确。旧阶段材料位于开发者本机历史备份，不属于当前用户手册。
