# 分享、隐私与发布

给普通Windows用户：发送GitHub Releases的便携ZIP，解压完整目录，双击Zhishi.exe。给开发者：发送源码ZIP或仓库链接。

公开源码由明确允许的app/floatbox源码、静态资源、提示词、启动与构建脚本、配置模板和本文档组成。排除.env、data、数据库、上传原件、个人日志、备份、venv、缓存、旧评估样本和历史工作记录。个人运行目录仍保留在开发者本机。

便携包使用同一干净源码构建，内含运行时和第三方依赖，不包含预建知识库。首次启动生成新数据库，初始处理模式为本地规则；收件人使用自己的模型账号。

发布前静态扫描：禁止敏感文件路径、检查本机密钥是否落入发布文件、检查常见令牌格式，并清点ZIP；扫描不打印密钥。发布文件以SHA256校验值核对。发布构建记录与旧评估报告分开，不能把早期指标当作本版本验证结果。

已使用过的便携目录含收件人的数据，不能直接转发给第三人。始终重新下载干净发布ZIP，或从明确白名单构建。配置文件不要上传GitHub，撤销泄漏密钥需要到供应商控制台完成。
